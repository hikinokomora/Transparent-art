# Transparent Art

[![Build](https://github.com/hikinokomora/Transparent-art/actions/workflows/build.yml/badge.svg)](https://github.com/hikinokomora/Transparent-art/actions/workflows/build.yml)

Бесплатное приложение для Android с открытым исходным кодом, которое помогает перерисовать любую картинку на бумагу.

1. Выберите фото в галерее. Приложение превратит его в линейный рисунок для карандаша.
2. Выберите режим и стиль, настройте линии, штриховку и цвет. Удерживайте превью, чтобы сравнить с оригиналом.
3. Нажмите «Рисовать». Эскиз ляжет полупрозрачным слоем поверх камеры. Поставьте телефон на подставку (стопка книг, стакан) в 20–30 см над листом, подгоните картинку жестами, закрепите замком и обводите.

Ни рекламы, ни аккаунтов, ни сети: приложение не запрашивает доступ к интернету, вся обработка идёт на телефоне.

## Скачать

Приложение готовится к публикации в [F-Droid](https://f-droid.org) — каталоге свободных приложений, где оно будет собираться из исходников и обновляться автоматически.


Готовые APK лежат на странице [Releases](https://github.com/hikinokomora/Transparent-art/releases/latest). Для большинства телефонов нужен файл `*-arm64-v8a.apk`; `*-armeabi-v7a.apk` — для старых 32-битных устройств. Скачайте APK на телефон и откройте его; Android попросит разрешить установку из этого источника.

## Возможности

- **Режим «Нейросеть»** для фотографий: модель [Informative Drawings](https://github.com/carolineec/informative-drawings) рисует фото так, как его нарисовал бы художник, — выделяет форму, черты лица, важные детали и пропускает фон и шум. Два стиля: «Контуры» (чистые линии) и «Набросок» (живой карандашный штрих). Работает офлайн, обработка занимает несколько секунд.
- **Классический режим** для рисунков, логотипов и простых картинок: быстрый фильтр по контурам и границам цветов с подавлением текстур.
- Настраиваемые чистота и насыщенность линий, 2–5 тонов штриховки, цвет линий
- Наложение на камеру с регулируемой прозрачностью
- Масштаб, перемещение и поворот картинки двумя пальцами
- Замок, чтобы случайно не сдвинуть картинку во время рисования
- Зеркальное отражение, фонарик, быстрое скрытие картинки
- Экран не гаснет, пока вы рисуете
- Интерфейс на русском и английском

## Советы

- Чем выше телефон над листом, тем меньше искажений по краям. Камеру лучше направлять на лист строго сверху.
- Если линии сливаются с карандашом на экране, смените цвет линий на красный или синий.
- Кнопка с глазом быстро скрывает картинку: удобно, чтобы посмотреть на свой рисунок без подсказки.

## Сборка

Нужны [Android Studio](https://developer.android.com/studio) (Ladybug или новее) или Android SDK и JDK 17+.

```bash
./gradlew assembleDebug
```

APK для каждого типа процессора появятся в `app/build/outputs/apk/debug/`.

Модели уже лежат в `app/src/main/assets/models/`. Чтобы пересобрать их из исходных весов, см. `tools/export_informative_drawings.py`.

Для подписанной release-сборки положите в корень проекта файл `keystore.properties`:

```properties
storeFile=/path/to/keystore.jks
storePassword=...
keyAlias=...
keyPassword=...
```

и выполните `./gradlew assembleRelease`. Без этого файла release-сборка получится неподписанной.

## Устройство проекта

| Файл | Что делает |
| --- | --- |
| `NeuralSketcher.kt` | Запуск модели Informative Drawings через ONNX Runtime |
| `SketchEngine.kt` | Классический фильтр на чистом Kotlin без OpenCV: цветовое пространство Lab, автоконтраст, guided filter, контуры по структурному тензору с подавлением текстур и гистерезисом; общая штриховка |
| `SketchProcessor.kt` | Параметры, выбор режима, обработка линий модели |
| `ImageLoader.kt` | Загрузка фото из галереи с масштабированием и поворотом по EXIF |
| `EditorScreen.kt` | Выбор фото и настройка эскиза |
| `TraceScreen.kt` | Наложение эскиза на камеру и управление жестами |
| `CameraPreview.kt` | Предпросмотр камеры через CameraX |
