# Как помочь проекту

Буду рад любой помощи: исправлениям, новым функциям, переводам и сообщениям об ошибках.

- **Ошибки и идеи:** создайте [issue](https://github.com/hikinokomora/Transparent-art/issues), по возможности укажите модель телефона и версию Android.
- **Код:** сделайте fork, создайте ветку, внесите изменения и откройте pull request. Перед этим убедитесь, что проект собирается: `./gradlew assembleDebug`.
- **Перевод:** добавьте папку `app/src/main/res/values-<код языка>/` с файлом `strings.xml` по образцу `values/strings.xml`.

Стиль кода — стандартный Kotlin (`kotlin.code.style=official`).
