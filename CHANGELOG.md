# Changelog

## [0.2.1] - 2026-10-17

### Исправлено
- Падение при обработке фото нейросетью в release-сборке: оптимизатор кода переименовывал классы ONNX Runtime

### Изменено
- У каждой архитектуры свой код версии (`versionCode * 10 + n`), сборку одной архитектуры можно выбрать параметром `-Pabi`
- Метаданные для F-Droid: описание, иконка, `.fdroid.yml`

## [0.2.0] - 2026-10-17

### Добавлено
- Режим «Нейросеть» для фотографий на основе модели Informative Drawings: работает офлайн, два стиля — «Контуры» и «Набросок»
- Настройки чистоты и насыщенности линий для этого режима
- Скрипт `tools/export_informative_drawings.py` для пересборки моделей из исходных весов

### Изменено
- Отдельные APK для arm64-v8a и armeabi-v7a
- Классический режим: новый алгоритм эскиза, рассчитанный на цветные картинки и фотографии:
  - контуры ищутся по цвету, а не только по яркости, поэтому видны границы между цветами одинаковой яркости
  - автоматическая коррекция уровней и гаммы для тёмных и блёклых снимков
  - сглаживание с сохранением краёв убирает шум и мелкую текстуру
  - подавление текстур: шерсть, трава и древесина не превращаются в россыпь штрихов
  - непрерывные линии без обрывков и точек
  - тени только в тёмных областях, с ровными границами зон
- Регулятор детализации теперь заметно меняет количество линий
- Штриховка по умолчанию выключена
- Маленькие картинки увеличиваются до рабочего размера, чтобы эскиз выглядел одинаково

## [0.1.0] - 2026-10-17

Первая публичная версия.

### Добавлено
- Превращение фото из галереи в эскиз для карандаша: контуры и 2–5 тонов штриховки
- Настройки детализации, чувствительности и толщины линий, насыщенности теней
- Выбор цвета линий: чёрный, красный, синий, зелёный
- Наложение эскиза на камеру с регулируемой прозрачностью
- Масштаб, перемещение и поворот картинки жестами, замок положения
- Зеркальное отражение, фонарик, быстрое скрытие картинки
- Экран не гаснет во время рисования
- Русский и английский интерфейс
